# Changelog

## 1.0.0-beta.2 — 2026-08-15

- exact bounded text change model with split diff and Unicode-aware change ledger
- corrected policy-scoped verification language when stricter findings remain
- XLSX and PPTX package-property, authorship and invisible-Unicode sanitation
- strict SVG sanitation for metadata, comments, active content and external references
- deeper PDF XMP, annotation privacy and JavaScript/launch/action inspection
- German/English renderer catalogs with locally persisted language selection
- restrained professional UI and project-owned NullMark SVG identity
- supported binary format set expanded from six to nine formats
- all cleaned outputs remain subject to independent structural reopen verification

## 1.0.0-beta.1 — 2026-08-15

- modular Rust engine split into model, rules and sanitizer policies
- Safe, Strict and Maximum sanitation modes
- expanded Unicode control, variation, private-use and compatibility coverage
- deterministic idempotency and canonical-projection invariants
- stale renderer result protection bound to the current input revision
- explicit probabilistic-watermark non-verifiable state
- exact npm/Rust direct dependency versions and committed lockfiles
- hardened repository security gate and reproducible Windows build chain
- GitHub CI, Dependabot, contribution policy, MIT license and threat model
- complete Tauri platform icon set generated from the local NullMark SVG
- policy-scoped verification no longer presents remaining findings as fully clean
- one-click escalation to the minimum sanitation mode required by remaining findings
- versioned roadmap for visual diff, XLSX/PPTX/SVG, deeper PDF inspection and i18n
- bounded batch analysis and verified export for PNG, JPEG, WebP, PDF, DOCX and ODT
- format-specific metadata removal, including PNG/JPEG/WebP/PDF/OOXML/ODF C2PA carrier removal
- hostile ZIP name/overlap/encryption/compression defenses and deterministic document rebuilds
- structural PDF parsing with Info/XMP removal and parser-level reopen verification

Statistical vendor text-watermark removal remains explicitly non-verifiable without a compatible detector.
